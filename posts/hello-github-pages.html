GitHub Pages

从 GitHub Pages 开始

2026-06-24 3 分钟阅读

这个博客先从最小可维护版本开始：纯 HTML、CSS 和一点点搜索脚本。这样做的好处是清楚、稳定，没有构建步骤，也不会因为依赖更新影响发布。

GitHub Pages 对个人博客很合适。仓库名是 Sunhuahai.github.io，静态文件放在主分支后，站点就可以发布到固定地址。

当前原则

第一版只保留真正需要的功能：主页、文章列表、文章页、站内搜索和 RSS。等内容积累到一定数量后，再增加归档、标签页和评论系统。

接下来

后续可以把这套结构继续演进成一个轻量写作系统，例如用 Markdown 作为源文件，再通过脚本生成静态页面。
