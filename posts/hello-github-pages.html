GitHub Pages

从 GitHub Pages 开始

2026-05-18 3 分钟阅读

这个博客先从最小可维护版本开始：纯 HTML、CSS 和少量 JavaScript。这样做的好处是清晰，没有构建步骤，也不会因为依赖更新影响发布。

GitHub Pages 对个人博客很合适。只要仓库名是 Sunhuahai.github.io，把静态文件推到主分支后，站点就会发布到固定地址。

当前原则

第一版只保留真正需要的功能：文章列表、文章页、搜索、深浅色主题和 RSS。等内容积累到一定数量后，再增加归档、标签页和更完整的导航。

接下来

后续可以把这套结构继续演进成一个轻量写作系统，例如用 Markdown 作为源文件，再通过脚本生成静态页面。
