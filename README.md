# 悟空的博客

这是 Sunhuahai 的 GitHub Pages 个人博客，采用纯 HTML、CSS 和少量 JavaScript 构建，风格保持纯白极简。

## 本地预览

直接打开 `index.html` 即可预览；也可以在仓库目录运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`。

## 更新文章

1. 在 `posts/` 新增文章 HTML。
2. 在 `index.html` 的文章列表中添加文章条目。
3. 在 `feed.xml` 中添加 RSS 条目。
4. 提交并推送到 `main` 分支。

GitHub Pages 发布地址：

```text
https://sunhuahai.github.io/
```
