# Site icon credits

The site favicon / app icon uses the seal-script form of the character **青**.

- Glyph source: [File:青-seal.svg](https://commons.wikimedia.org/wiki/File:青-seal.svg) on Wikimedia Commons (Ancient Chinese characters project; Shuowen small seal / 小篆).
- License: Public domain (ancient script; ACC release on Commons; attribution appreciated).
- Treatment: white glyph on black ground (app-icon style), derived without altering stroke geometry.
